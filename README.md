# Skill Zoo

A deliberately small collection of failure-driven skills for AI coding agents.

**Skills are useful. Evidence matters. Context isn't free.**

## What belongs here?

A skill must justify:

1. **Existence** — What concrete failure or capability does it address?
2. **Residency** — Does it have enough bounded, honest evidence for the Zoo to stand behind it?
3. **Claim** — What exactly does the evidence support?

```text
Zoo:
incubating ≠ resident

Runtime:
installed ≠ loaded ≠ invoked
```

A **Zoo resident** is an admitted artifact. It does **not** mean the skill should be permanently loaded into every user's context.

Runtime loading is a separate deployment choice: always-loaded, on-demand, project-local, user-choice, or not installed.

See [`CONSTITUTION.md`](CONSTITUTION.md) for the operating rules.
